# OneCrew Landing

A fully animated static landing page for OneCrew.

## Run locally

```bash
python -m http.server 5173
```

Then open http://localhost:5173

## Files

- `index.html` — complete landing page
- `styles.css` — responsive premium UI and animations
- `script.js` — reveal and parallax interactions
- `public/crew/` — OneCrew mascot assets
